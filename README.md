# Rinngo Lab

用 AI 协作，把想法做成可运行的作品。

个人 AI 编程作品集站点（Astro 静态站），展示安卓在线翻译、在线文档系统、工单管理看板、抖音视频批量下载等实践。

在线预览：https://rinngo01.github.io/rinngo-lab/

## 使用方法

### 安装依赖

```bash
npm install
```

### 本地开发

```bash
npm run dev
```

浏览器访问 `http://localhost:4321`

### 构建与预览

```bash
npm run build
npm run preview
```

### 更新内容

- 作品：编辑 `src/content/works/*.md`
- 博客：编辑 `src/content/posts/*.md`
