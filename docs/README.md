# AI 编程作品博客（Rinngo Lab）

用 AI 协作，把想法做成可运行的作品。

个人 AI 编程作品集站点，基于 Astro，展示安卓在线翻译、在线文档系统、工单管理看板、抖音视频批量下载等实践。

## 使用方法

```bash
npm install
npm run dev      # 本地开发，访问 http://localhost:4321
npm run build    # 生产构建
npm run preview  # 预览构建结果
```

### 更新内容

- 作品：`src/content/works/*.md`
- 博客：`src/content/posts/*.md`
